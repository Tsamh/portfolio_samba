# Images du carrousel Projects

Dépose ici tes photos (`.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`, `.gif`).

- Elles sont chargées automatiquement, triées par nom de fichier
  (`01.jpg`, `02.jpg`, … pour contrôler l'ordre).
- Format conseillé : portrait, ~600×800px.
- Tant que ce dossier ne contient pas d'images, des photos
  de remplacement (picsum.photos) sont affichées.
